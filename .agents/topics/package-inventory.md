# Package contracts

Use this inventory to locate a package and its public integration boundary. Release versions belong to the manifests, not this table. Read the corresponding architecture topic before changing its behavior.

| Package | Description |
|---------|-------------|
| `@vuecs/button` | General-purpose button (color/variant/size, loading, icon slots) + polymorphic `:as` (string tag or component — render as `RouterLink` / `NuxtLink` for button-styled links; deprecated `tag` alias) |
| `@vuecs/core` | Theme system, global behavioral defaults, utilities, component infrastructure. Also exports `VCPrimitive` (ported `as` / `asChild` building block) + `usePrimitiveElement` so downstream component libraries don't need a direct `reka-ui` dep, and the `GenericComponentShape<Props, Slots>` helper for authoring `defineComponent`-style components that stay generic over a consumer entity type (shared by `@vuecs/table`, `@vuecs/list`, and third-party libs — issue #1601, #1660). Also owns the promoted collection helpers `resolveItemIdentity()` + `createCollectionMutations()`. |
| `@vuecs/countdown` | Countdown/timer component |
| `@vuecs/data` | Loader-backed data-source composables — `defineDataCollection()` (structural superset of `ListState & ListMutators`; binds to `<VCList :state>`, future `<VCTable :source>`) + `defineDataRecord()` (single-entity source: `ensure()` / `set` / `merge` / `clear`) over one shared async core (counter-busy, token-guarded latest-wins, `error` ref — `load` captures, `mutate(fn)` rethrows —, `dehydrate`/`hydrate`, and D12 mutator buffering that drains FIFO after an in-flight load settles, error included). `load(next?, input?)` hands the loader a meta **draft** plus a per-call `input`, commits the draft into `meta` only when the call applies, and resolves a `DataLoadOutcome` (`applied` / `superseded` / `failed`, plus `cached` from `ensure(input?)`); mutators return `applied` / `buffered` / `noop` with an `onSettled` callback, and record `set` / `clear` accept `{ immediate: true }` (drain, supersede in-flight loads, apply). Status vocabularies are the `DataLoadStatus` / `DataMutationStatus` enums in `constants.ts`, with `` `${Enum}` `` literal types in `types.ts`. Opt-in `deep: true` holds data in a `ref` and updates rows / merges records in place. Patch merges (record `merge`, collection `mergeOnUpdated`) run through one configured smob merger: deep merge with the **patch winning**, arrays **replace** rather than concatenate, inputs cloned, and explicitly-`undefined` keys skipped (pass `null` to clear). `@experimental`, published on the **alpha prerelease channel** (`x.y.z-alpha.N`, npm dist-tag `alpha` — API may break without a major bump). |
| `@vuecs/design` | CSS design tokens (concrete OKLCH defaults from Tailwind v4's palette + semantic aliases) + motion primitives (vanilla-CSS port of `tw-animate-css`) + theme-agnostic `useColorMode` + theme-aware `useColorPalette` (dispatches through installed themes' `palette.handle` hooks) + canonical `ColorPaletteConfig` type + generic palette primitives (`applyColorPaletteCss`, `bindColorPalette<T>`, `COLOR_PALETTE_STYLE_ELEMENT_ID`) for any theme to compose. No Tailwind dep — works standalone with BS/Bulma/no theme. |
| `@vuecs/elements` | Atomic, presentation-only UI elements — `VCSeparator`, `VCTag` / `VCTags`, `VCAvatar`, `VCAspectRatio`, `VCVisuallyHidden`, `VCBadge`, the Card compound (`VCCard` / `VCCardHeader` / `VCCardTitle` / `VCCardDescription` / `VCCardBody` / `VCCardFooter`) + `VCCardPlaceholder` (skeleton sibling), the Alert compound (`VCAlert` / `VCAlertTitle` / `VCAlertDescription` / `VCAlertClose`), and the Collapse compound (`VCCollapse` / `VCCollapseTrigger` / `VCCollapseContent`, Reka `Collapsible` wrapper). Pure-CSS or thin Reka wrappers; each ≤150 LOC, owns its own theme key. |
| `@vuecs/forms` | Form components on Reka UI primitives — `VCFormCheckbox` / `VCFormCheckboxGroup`, `VCFormSwitch`, `VCFormRadio` / `VCFormRadioGroup`, `VCFormPin`, `VCFormSlider` (single+range), `VCFormNumber`, `VCFormTags`, `VCFormSelect` / `VCFormSelectSearch` (FormOption shape), `VCFormInput` / `VCFormTextarea` (native; their value is set as a DOM property through the internal `vDomValue` directive, never a `value` vnode prop, which Vue mirrors into the attribute and so into the markup), plus the experimental `useSubmitButton()` helper for `@vuecs/button`. Renamed from `@vuecs/form-controls` in 3.0. |
| `@vuecs/gravatar` | Gravatar avatar component — composes `<VCAvatar>` from `@vuecs/elements` for fallback support |
| `@vuecs/icon` | `<VCIcon>` component — thin Iconify wrapper for vuecs's icon-string-prop slots and consumer slot content |
| `@vuecs/link` | Router-aware link component (vue-router/nuxt). Public prop type is `LinkProps`, derived from the prop declaration via `ExtractPublicPropTypes`. |
| `@vuecs/list` | Compound list (List / Body / Item / Empty / Loading) + `defineList()` factory + `useList()` / `useListItem()` injectors + built-in `v-model:selection` (single / multi, ARIA listbox). Header / footer / item-text / item-actions are consumer markup driven by slot-prop class strings. `VCList` / `VCListItem` are **generic over `Item`** so `<VCListItem :data>`'s `#default` slot (and `<VCList>`'s `:data` / `:state`) infer the consumer's row type (issue #1660 — same `defineComponent` + generic-cast facade as `@vuecs/table`; context-reading parts stay non-generic). Successor to `@vuecs/list-controls` — clean break. Shared identity and mutation helpers live in `@vuecs/core`. |
| `@vuecs/locale` | Browser-language-aware, resettable locale source. `useNavigatorLanguage`-backed (via `@vueuse/core`); source is a BCP-47 tag or the `'auto'` sentinel (color-mode `'system'` analog) that defers to the browser. Install plugin bridges the resolved value into `@vuecs/core`'s `Config['locale']`, persists the source, and syncs `<html lang>`. `useLocaleManager()` exposes `set` (apply a backend-saved override) / `reset` (back to `'auto'`) / `source` / `resolved` / `isAuto`; `bindLocale()` is the lower-level building block (parallels `bindColorMode`). Read-side consumers use `useLocale()` from `@vuecs/core`. |
| `@vuecs/navigation` | Multi-level navigation — per-call-site `:data` items + a shared reactive registry for dependent navs + `<VCStepper>` compound for multi-step wizards + the `<VCBreadcrumb>` compound (7 parts, generic over `Item`; `:items` driver / manual compound / registry-`activeTrail` derivation; `useBreadcrumb()` app-scoped push/pop manager, `useBreadcrumbItems()` route-meta floor, `useBreadcrumbLeaf()` dynamic-`/:id` leaf override) |
| `@vuecs/nuxt` | Theme-agnostic Nuxt module — auto-imports `@vuecs/design` tokens, ships SSR-safe color-mode + palette + locale plugins (`useColorMode` / `useColorPalette` / `useLocale` / `useLocaleManager` auto-imports). Dispatches palette + colorMode runtime hooks through whichever themes the consumer installs. The cookie-backed locale plugin is universal (server+client), resolves `'auto'` from `Accept-Language` server-side, bridges into `Config['locale']`, and emits `<html lang>`. Optional `themes: string[]` config auto-generates a plugin that installs listed theme packages. |
| `@vuecs/overlays` | Compound overlays on Reka primitives — Modal (+ `useModal()` view-stack composable), AlertDialog (Reka `AlertDialog`; the `role="alertdialog"` confirm primitive — `Trigger`/`Content`/`Title`/`Description`/`Cancel`/`Action`) + the imperative `useAlertDialog()` → `Promise<boolean>` composable + single `<VCAlertDialogProvider>` host, Popover, HoverCard, Tooltip, DropdownMenu, ContextMenu, Toast (+ `useToast()` shared queue composable) |
| `@vuecs/pagination` | Pagination component |
| `@vuecs/placeholder` | Primitive skeleton loading components — `VCPlaceholder` (single animated bar, `shape: rect / pill / circle`, `size: xs–xl`, `duration` override) + `VCPlaceholderWrapper` (conditional `#loading` / `#default` slot switch with W3C "Loading content" ARIA wiring). Wave / glow / none animation modes; reduced-motion respected. Composite skeletons live next to the real components they mirror (`<VCCardPlaceholder>` in `@vuecs/elements`, `<VCTablePlaceholder>` in `@vuecs/table`). Pure-CSS + theme-class strings; ships its own structural CSS so it works without any theme. (issue #1476) |
| `@vuecs/table` | Compound table (`VCTable` + `VCTableLite` + Header / Body / Footer / Row / Cell / HeadCell / Empty / Loading / SortIndicators / Placeholder / ExpandTrigger / RowExpansion) with a `:columns :data` driver, default cell renderer (`accessor` + `formatter`), driver auto-render of header/body, stacked responsive mode, controlled `v-model:sort` on `VCTable` with multi-column + client-side sort, opt-in row-click + row keyboard nav, `_rowVariant` / `_cellVariants` row-meta, a discoverable `<VCTableSortIndicators>` chip-row for managing multi-sort without Shift-click, `<VCTablePlaceholder>` skeleton sibling for loading states, per-row expansion panels (`<VCTable :expandable>` + `#expansion` slot — ResizeObserver-measured height animation, W3C disclosure ARIA), and **generic over `Row`** so driver slot props (`#cell-<key>`, `#header-<key>`, `#expansion`) infer the entity type from `:data` / `:columns` (issue #1601 — `defineComponent` + generic cast, not `<script setup generic>`). Layer 1 — depends on `@vuecs/core` + `reka-ui` (the latter only for `<Presence>`-backed expansion unmount delay). |
| `@vuecs/theme-bootstrap` | Bootstrap theme (targets Bootstrap 5) |
| `@vuecs/theme-bulma` | Bulma 1.0+ theme + design-token bridge |
| `@vuecs/theme-tailwind` | Tailwind v4 theme (class strings + `merge: ClassesMergeFn`) + Tailwind palette runtime (`setColorPalette`, `renderColorPaletteStyles`) + Tailwind rebind / `@theme` block / `@source inline()` safelist. Contributes its renderer via `palette.handle` so `useColorPalette()` from `@vuecs/design` dispatches through it. `useColorPalette` / `ColorPaletteConfig` now live in `@vuecs/design`; deprecated re-exports remain for one release cycle. |
| `@vuecs/icons-font-awesome` | Font Awesome 6 Solid icon-name preset for vuecs (Iconify-backed) |
| `@vuecs/icons-lucide` | Lucide icon-name preset for vuecs (Iconify-backed) |
| `@vuecs/timeago` | Relative time display component |
| `@vuecs/tree` | Tree view (`VCTree` + `VCTreeItem` + `VCTreeItemTrigger`) — a nested item list that **selects** rather than navigates (vs `@vuecs/navigation`'s `<VCNavItems>`). Wraps Reka's `TreeRoot` / `TreeItem` as a focus/flatten shell; vuecs owns selection, expansion and the cascade. Key-based `v-model:selection` (strings, not item objects — round-trips into a `?path=` query param) with `:multiple`, `:cascade` (whole-subtree select + `aria-checked="mixed"` on partial branches, collapsed ones included), controlled `v-model:expanded` / `:default-expanded`, lazy children via `:load` + `:has-children`, and `:item-id` / `:item-key` / `:get-children` / `:get-label` / `:item-disabled` accessors. **Generic over `Item`** so `:items` types the `#item` / `#toggle` slot props (issue #1601 pattern, on both `<VCTree>` and `<VCTreeItem>`). Also exports the Vue-free utils `parseTreePaths()` / `buildTreeIndex()` / `normalize()` / `cascadeSelect()` / `orderKeys()`. Two theme keys (`tree`, `treeItem`); indentation ships in its own structural CSS via `--vc-tree-level`, so it renders with no theme installed. Layer 1 — depends on `@vuecs/core` + `reka-ui`. |
